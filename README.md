🛍️ Shopping App (Practice Project)

Shopping App is a practice Flutter application created to improve mobile development skills using Flutter.
This project is built for learning purposes only and is not intended for production use.



📌 About the Project

This is a simple e-commerce style application developed with Flutter. The main goal of this project is to practice Flutter fundamentals, including UI design, state management basics, project structure organization, and working with widgets and layouts. It demonstrates a simple shopping flow with product listing and basic cart functionality.



## 🛠️ Installation & Setup

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/T0WHIDM/shopingapp.git

2. **Navigate to the project directory:**
   ```bash
   cd shopingapp

3. **Install dependencies**:
   ```bash
     flutter pub get
   
4. **Run the app**:
   ```bash
      flutter run

Make sure you have the Flutter SDK installed and properly configured on your system.
